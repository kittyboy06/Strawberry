# Strawberry CLI 🍓

Standalone Windows CLI (`Lite`) and Textual TUI (`Pro`) client for offline-first laboratory program retrieval.

For full setup, architecture, and Windows installer documentation, see the root [README.md](../README.md) and [docs/installation.md](../docs/installation.md).

## Quick Commands

```bash
uv sync
uv run strawberry --version
uv run pytest -v
```
